# Portfolio Website

Persoonlijke portfolio-website gebouwd met HTML, CSS en JavaScript.
door Joost Bosgoed
## Structuur

```
portfolio/
├── index.html        # Hoofdpagina
├── css/
│   └── style.css     # Stijlen
├── js/
│   └── main.js       # Functionaliteit
├── images/
│   └── ...           # Afbeeldingen
└── README.md
```

## Functies

- **Responsive design** - werkt op mobiel en desktop
- **Secties**: Home, Over mij, Projecten, Contact
- **Contactformulier** - basis validatie

## Gebruik

Open `index.html` in een browser of gebruik een lokale server:

```bash
# Met Python
python -m http.server 8000

# Met Node.js (indien geinstalleerd)
npx serve .
```
